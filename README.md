## 🛠️ Stack

| Camada         | Tecnologia                        |
|--------        |------------                       |
| Backend        | Node.js + Express                 |
| Banco de dados | PostgreSQL                        |
| Frontend       | HTML + CSS + JavaScript (Vanilla) |
| ORM/Query      | pg (node-postgres)                |

## 🚀 Como rodar o projeto localmente

```bash
cd backend
cp .env.example .env
npm install
npm run migrate
npm run dev
```

Servidor em `http://localhost:3000`.
